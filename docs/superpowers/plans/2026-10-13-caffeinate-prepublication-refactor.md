> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Simplify Caffeinate around Node 24, replace handwritten terminal machinery with standalone pi-tui, and prove the bundled application retains its accepted behavior before publishing infrastructure begins.

**Architecture:** Preserve the lease model, Herdr socket adapter, per-server monitor, private IPC, and native assertion ownership. One strict TypeScript project checks all owned code against Node 24 types independently of the JavaScript build.

## Global Constraints

- **Node 24.x only for development and runtime.** Use `engines.node: "^24.0.0"`, explicit error-only `devEngines.runtime` for the same range, and a matching launcher check. This is a supported-major policy, not a pin to one Node patch. Reject other majors without provisioning a runtime.
- **Supersedes the earlier Node 22 proposal:** no second Node types package, project references, declaration bridge/cache, or `undici-types` override. Keep a single strict `tsc --noEmit` project covering source, tests, fixtures, probes, scripts, and build configs.
- macOS consumers; Herdr minimum **0.9.3**, newer versions accepted best-effort. No SQLite, Pi agent SDK, shared UI framework, bundled Node runtime, or separate consumer npm dependency installation.
- Application TypeScript uses extensionless relative imports with `module: "ESNext"` and `moduleResolution: "Bundler"`. Node-executed developer files retain resolvable `.ts` helper imports or package aliases. TypeScript resolution is not a Node runtime loader.
- Match agentlog's distribution strategy: bundle, tree-shake, and minify production JS; disable code splitting; retain development-only modular JS for unit tests. This deliberately supersedes the previous unbundled-output decision, not a separate size-optimization project.
- Eight-hour default absolute deadlines; ten-second automatic delay anchored to run start; independent leases; provisional AC-only protection; uncertainty never grants or renews leases. Never cancel or send input to an agent.
- Preserve Agents (`a`) / Settings (`s`) / About (`?`), focused-agent targeting, stable occupant identity, form drafts, duration validation, mouse/keyboard controls, 56×18 minimum, and Gruvbox/custom/fallback colors. Popup closure does not stop the monitor or release leases.
- Preserve `/usr/bin/caffeinate -i -w <monitor PID> -t <seconds>` ownership, finite timeouts, public CLI command names, manifest action IDs, the compatibility shim, and monitor IPC contracts.
- Exact direct dependency pins and committed lockfile. Preserve `engineStrict: true`, `minimumReleaseAge: 10080`, `minimumReleaseAgeStrict: true`, `minimumReleaseAgeIgnoreMissingTime: false`, `blockExoticSubdeps: true`, `trustPolicy: no-downgrade`, `trustLockfile: false`, `strictDepBuilds: true`, `allowBuilds: {}`, and `saveExact: true`.
- Retain all six Oxlint plugins (`eslint`, `typescript`, `unicorn`, `oxc`, `import`, `node`), type-aware checking, warning failures, Oxfmt, and independent compiler/linter canaries. No blanket `any`, lint suppressions, or excluded owned tests to obtain a pass.
- Keep one canonical repository-root `LICENSE`; copy it into the prepared payload. Preserve exact upstream license/copyright/required notice text for redistributed third-party code, even when minification removes comments.
- No normal-trial restart/relink, user configuration edits, global provisioning, automatic native assertion probes, publication, or branch-policy changes. Live sandbox/native acceptance requires explicit permission; ordinary tests remain deterministic and non-live.

## Review Focus

1. **An active agent disappears while another remains caffeinated:** release only the vanished agent's assertion and token, without renewing the survivor — Tasks 1 and 5.
2. **Rows change identity/order between rendering and activation:** never apply a command to a replacement or neighboring agent — Task 4.
3. **Unicode, terminal escapes, narrow sizes, and fragmented input:** safe display, correct mouse targeting, bounded rendering, usable editing and Escape — Tasks 2, 4, and 5.
4. **Popup closes during initialization, refresh, or a command:** restore terminal modes once, suppress late paints/unhandled rejections, close only its client, preserve the monitor — Tasks 4 and 5.
5. **A clean bundle runs without checkout dependencies or optional helpers:** help, popup, lazy imports, and detached monitor self-launch work; required notices and licenses accompany it — Tasks 2, 3, and 5.
