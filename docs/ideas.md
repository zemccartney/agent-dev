# Scratch ideas

Possibilities to revisit, not commitments or implemented features.

## pi-lence: focus mode

Hide prior conversation from view so the current turn gets the attention.

- Presentation only: retain session history, model context, pins, and draft text.
- Keep prior responses retrievable and provide a way to return to the full view.
- Preserve visibility of permissions, errors, and the current activity warning.
- Explore feasibility with pi's extension APIs before choosing an implementation.
- Revisit exactly what counts as prior conversation and how to toggle the view.
